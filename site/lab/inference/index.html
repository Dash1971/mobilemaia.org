What this measures.

  • Download and verification: model and runtime byte sizes and SHA-256 are checked, including cached files.
  • Startup: session creation and the first inference are recorded separately.
  • Correctness: eight model-specific native-reference results cover two positions, two ratings, and history on/off. The 5M checks also compare value logits and selected policy logits. A mismatch stops the test.
  • Warm performance: median, p95 and individual timings include input preparation, all model outputs and CPU readback. The eight reference runs warm up the session first.

CPU tests use one WebAssembly thread, matching this public host’s lack of cross-origin isolation. WebGPU may still run unsupported operations on CPU; this test does not measure per-operation placement. Compare the reported backend and run conditions.

This is a foreground inference benchmark. Whole-app startup, installation, background behavior, battery life and total native/GPU memory need separate tests. No full-memory measurement is claimed. The loader holds the full model in memory, with temporary copies during hashing and session creation; its peak memory use has not been optimized. Input positions are fixed reference cases, not a representative game sample.

Your data and downloads.

Inference runs on your device. On Start, this page downloads the pinned model from GitHub and a pinned runtime binary from jsDelivr. Those providers receive normal download requests. JavaScript is served locally; there are no analytics or automatic result uploads. Saving results creates a local JSON file for you to share manually.

Saved downloads use a cache reserved for this experiment. Browsers can evict it. Clear saved downloads removes only this experiment’s model and runtime cache. Close the tab to release any remaining browser memory.
